# ADR-0003: Неизменяемые инженерные записи

**Статус:** принято · 21.10.2026

**Контекст.** ТЗ 2.3, 5.5, 9.7: история состояния сохраняется, инженерные оценки нельзя незаметно изменить задним числом, отчёт скачивается повторно без изменения содержания.

**Решение.**
- Оценка риска, события статусов, проверки, наблюдения и журнал аудита наследуют `ProtectedHistoryModel` (удаление запрещено); `RiskAssessment` и `AuditEvent` запрещают и обновление.
- Утверждённое обследование исправляется новой версией (`supersedes`).
- Отчёт хранит `snapshot` данных на момент генерации и SHA-256 PDF.

**Последствия.** Требования о сроках хранения и удалении персональных данных (ТЗ 9.5) потребуют отдельной процедуры анонимизации — удаление записей напрямую невозможно.
