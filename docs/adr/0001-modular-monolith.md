# ADR-0001: Модульный монолит

**Статус:** принято · 21.10.2026

**Контекст.** MVP решает один сквозной процесс для пилота на одном здании; команда небольшая. ТЗ 8.2 прямо исключает микросервисы, Kubernetes и сложную событийную инфраструктуру без доказанной необходимости.

**Решение.** Один Django-проект, разделённый на приложения по модулям ТЗ (M01–M12). Межмодульные вызовы — через `services.py` модуля, а не через прямое изменение чужих моделей. Next.js — отдельное приложение в том же репозитории.

**Последствия.** Одна БД и одна транзакция на запрос упрощают атомарность. Границы модулей держатся дисциплиной (`services.py`), а не сетью; при необходимости модуль можно выделить позже.
