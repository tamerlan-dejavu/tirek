# ADR-0002: Единая точка авторизации по связи «организация — дом»

**Статус:** принято · 21.10.2026

**Контекст.** ТЗ 4.3/9.2: проверки роли недостаточно; доступ зависит от организации пользователя, её связи с конкретным домом и периода действия этой связи. Нужны негативные тесты на прямые API-запросы.

**Решение.** Все правила — в `apps/core/access.py`:
`accessible_building_ids(user, roles)` для фильтрации querysets и `require(user, building_id, *roles)` для мутаций. Роли хранятся в `OrganizationMembership`, а не на пользователе. Связь `BuildingOrganizationLink` имеет `valid_from/valid_to` и никогда не удаляется. Чужие записи отдают 404.

**Последствия.** Любой новый endpoint, связанный со зданием, наследует `BuildingScopedViewSet`. Изменение модели доступа затрагивает один файл и `tests/test_isolation.py`.
