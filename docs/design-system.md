# Дизайн-система Tirek · Premium SaaS Minimalism

> Инженерная точность. Ясность процессов. Доверие к данным.
> «Мы не заменяем ОСИ. Мы становимся его техническим партнёром».

## 1. Концепция

Строгий минимализм уровня современных B2B SaaS (ориентиры по характеру — Linear, Vercel, Stripe):
почти чёрный графитовый фон, глубина за счёт **типографики, отступов, контраста поверхностей и линий 1 px**,
а не теней, свечения и градиентов. Один сдержанный акцент — синий; цвета риска R1–R4 только по смыслу.

Инженерный характер сохраняется в содержании, а не в декоре:

| Приём | Где | Зачем |
| --- | --- | --- |
| Технический индекс раздела (`01 · Обзор · портфель объектов`) | шапки страниц, панели (`02`, `A`, `B`) | ориентация в разделах |
| Моноширинные метки `label-tech` | ID, категории, подписи полей и таблиц | технические обозначения, табличные цифры |
| Схема фасада со штампом «СХЕМА · НЕ В МАСШТАБЕ» | здание, дефект, кабинет ОСИ, лендинг | пространственное понимание без ложной точности |
| Сетка-калька (`grid-blueprint*`) | только фон схем и пустых состояний, почти невидима | не перегружает композицию |

Публичный сайт и рабочая платформа используют **одну тёмную палитру**; сайт отличается крупной типографикой и воздухом.

## 2. Токены (`frontend/src/app/globals.css`)

Все цвета, шрифты, радиусы и длительности управляются из одного `@theme`.

### Цвет

| Токен | Значение | Применение |
| --- | --- | --- |
| `base` / `canvas` | `#0C0D10` | фон страницы и навигации |
| `base-2` | `#111317` | едва заметная смена фона секций |
| `surface` | `#16181D` | карточки, панели, поля ввода |
| `mist` | `#1D2026` | вторичные поверхности, hover, треки графиков |
| `line` / `line-strong` | `#292C33` / `#3A3E47` | границы и разделители 1 px / поля ввода |
| `ink` | `#F5F5F7` | основной текст |
| `muted` | `#969BA6` | вторичный текст (≈ 7:1) |
| `faint` | `#6B7280` | приглушённые технические подписи 11–12 px (≈ 4.1:1, не для абзацев) |
| `accent` / `accent-strong` | `#3B82F6` | основной акцент, ссылки, основная кнопка |
| `accent-hover` | `#2563EB` | hover основной кнопки |
| `steel` / `steel-2` | `#8B93A1` / `#4B5260` | нейтральные линии схем и столбцы графиков |

Семантика — базовый цвет для заливок, `-ink` (светлее) для текста на тёмном, `-soft` для подложек 12 %:
`critical #EF4444 / #F87171`, `warning #F59E0B / #FBBF24`, `healthy #10B981 / #34D399`,
`info #38BDF8 / #7DD3FC`, `unknown #94A3B8 / #CBD5E1`.

Шкала риска: `r1 #EF4444` · `r2 #F59E0B` · `r3 #38BDF8` · `r4 #94A3B8`.
Цифры в маркерах риска на схеме — тёмные (`base`): светлые заливки R2–R4 не дают контраста с белым.

### Типографика

| Шрифт | Пакет | Применение |
| --- | --- | --- |
| **Manrope** 600–700 | `@fontsource-variable/manrope` | заголовки h1–h3, словесный знак |
| **Inter** 400–500 | `@fontsource-variable/inter` | текст, навигация, кнопки, формы |
| **IBM Plex Mono** 400–500 | `@fontsource/ibm-plex-mono` | ID, категории, технические подписи; не для абзацев |

Все шрифты подключены локально (без Google Fonts), с кириллицей.
Шкала сайта: H1 `clamp(2.5rem, 6vw, 4.5rem)` 700, H2 `clamp(1.875rem, 3.4vw, 3rem)` 600, текст 17–18 px;
платформа: заголовок страницы 26–32 px, панели 15 px, текст 14–15 px, технические метки 11 px.
Крупные заголовки — `letter-spacing` от −0.02 до −0.04 em.

### Геометрия, глубина, движение

- Отступы — сетка 4/8 px. Ширина контента сайта 1240 px; секции 80 / 112 / 128 px (mobile / md / lg); карточки 20–24 px.
- Радиусы: `xs 4 · sm 6 (мелкие элементы) · md 8 (поля) · button 10 (кнопки) · lg 12 (карточки) · xl 16 (модальные окна)`.
- Глубина — поверхности и границы 1 px. `shadow-overlay` только у всплывающих слоёв (меню, подсказки, просмотр фото).
- Движение: `fast 150 ms`, `base 200 ms`, `slow 250 ms`, кривая `ease-precise`; появление — 250 ms, смещение 4 px.
  Прорисовка чертежа (`draw-path`) сохранена на лендинге и при первом показе схемы.
  `prefers-reduced-motion` отключает анимации.

### Кнопки

| Вариант | Вид |
| --- | --- |
| `primary` | фон `#3B82F6`, белый текст, hover `#2563EB`, радиус 10 px, без свечения |
| `secondary` | прозрачный фон, граница `line`, светлый текст, hover — `mist` |
| `danger` | прозрачный фон, граница и текст `critical` |
| `inverse` / `inverse-outline` | алиасы `primary` / `secondary` (исторические имена на лендинге) |

Фокус — контур 2 px `accent` у всех интерактивных элементов.

## 3. Семантика: два независимых измерения

| Измерение | Компонент | Кодирование |
| --- | --- | --- |
| **Серьёзность** (экспертная категория R1–R4) | `RiskBadge`, `SeverityMeter` | цвет + форма иконки (восьмиугольник / треугольник / ромб / круг) + 4-сегментный индикатор + текст |
| **Статус процесса** | `StatusBadge` | нейтральный чип с точкой тона; никогда не заливается цветом риска |
| **Утверждённость** | `ApprovalTag` | «Утверждено» — сплошной; «Предварительно» — пунктир |

Предварительная серьёзность (оценка полевого специалиста) показывается **пунктиром** с «предв.» —
её нельзя спутать с утверждённой инженером категорией. Критический дефект может быть «В работе» — оба признака видны одновременно.

## 5. Схема здания (`BuildingElevation`)

- Геометрия строится **только из паспорта**: этажность × подъезды. Неизвестное — «неизвестно», заглушка нейтральна.
- Дефект размещается по **зоне** (кровля / фасад / подвал / инженерные системы) и подъезду из иерархии элементов,
  а не по координатам. Штамп листа: «СХЕМА · НЕ В МАСШТАБЕ · расположение по зонам».
- Инженерные системы без привязки к фасаду — в отдельной полосе под отметкой земли.
- Маркер: заливка = утверждённый риск; пунктирный контур = оценка не утверждена. Номер маркера = номер в списке.
- Доступность: каждый маркер фокусируется с клавиатуры, имеет `aria-label`; под схемой — полный список-эквивалент со ссылками.
- Технология — SVG: достаточно для задачи, без 3D-движка ради эффекта.

## 6. Адаптивность

| Ширина | Поведение |
| --- | --- |
| ≥ 1280 px | двухколоночные рабочие экраны, таблицы со всеми колонками |
| 1024–1279 | навигация-рельс, панели в одну-две колонки |
| < 1024 | навигация в выезжающем меню; вторичные колонки таблиц скрыты |
| < 640 (телефон) | чек-лист: закреплённый прогресс, разделы-чипы, нижняя панель отправки, камера через `capture` |

## 7. Чего избегаем

Сводные «индексы состояния» без методики · выдуманные результаты и отзывы · декоративные градиенты, неон и glassmorphism ·
цвет как единственный носитель смысла · цвета риска как украшение · «цифровой двойник» без пространственных данных ·
моноширинный шрифт в абзацах.

## 8. Публичный сайт

Секции A–I (`app/(public)/page.tsx`): hero со схемой фасада и выносками · проблема · процесс из 6 шагов ·
интеллект здания (реальные компоненты на данных с пометкой «демо») · жизненный цикл дефекта · план профилактики ·
разделение ответственности с ОСИ · структура отчёта (образец) · призыв к действию.
Контакт для CTA задаётся `NEXT_PUBLIC_CONTACT_EMAIL`; без него CTA ведёт на вход для партнёров.
